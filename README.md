# PayPal AI Hackathon 2026 — Entry

## Objective
Win a prize at the PayPal AI Hackathon (global online hackathon, $69,750 total prizes) with an AI + PayPal-sandbox app that scores on all five judging criteria — especially Technological Implementation, Design, and Best Use of Agentic Commerce.

## Source of Truth
- Competition rules: `docs/competition.md` (researched from the official Devpost page, Oct 4 2026)
- Win plan: `docs/win-plan.md`
- Official site: https://paypalaihackathon.devpost.com

## Done When
- [ ] Working app deployed to a hosted demo URL (PayPal sandbox + AI, genuinely integrated)
- [ ] Public GitHub repo with all source, run instructions, and a visible LICENSE (this repo)
- [ ] Demo video under 3 minutes on YouTube, publicly visible
- [ ] Devpost submission complete before **Nov 12, 2026, 3:00 PM EST**
- [ ] Chris explicitly approves the submission before anything is posted

## Acceptance Criteria
- Judges can run or interact with a working build (hosted URL or complete run instructions) — a mockup does not qualify
- PayPal integration is central, not decorative (sandbox environment)
- AI is meaningfully incorporated into the experience or functionality
- Video shows the project functioning end-to-end on the device it was built for

## Constraints
- Open Chris-held item: the Devpost entry questionnaire answers are still needed from Chris
- Use the free PayPal sandbox — no real money moves
- No third-party trademarks or copyrighted music/material in the demo video without permission
- Entry may be individual or team; all work must represent genuine effort during the hackathon window
- Nothing submits without Chris's explicit approval

## Non-Goals
- Production-grade infra (this is a working prototype / proof of concept)
- Real-money PayPal integration
- Winning sponsor tool prizes at the expense of the core concept

## Verifier
Chris reviews the hosted demo and the video, then approves the Devpost submission.
