# PayPal AI Hackathon — Official Competition Facts

Researched Oct 4, 2026. Sources: the live Devpost page (https://paypalaihackathon.devpost.com), verified by the campaign lead from the official rules.

## Organizer
PayPal — global online hackathon. Judges include PayPal developer advocates and engineers (Jo Franchetti, Eddie Jaoude, Marco Podien, Karthik Ravi, Himraj Singh, Nathaniel Olson) plus sponsor judges.

## Scale
- **4,957 participants** registered so far (as of Oct 4, 2026)

## Key dates
- **Submission deadline: November 12, 2026, 3:00 PM EST**
- Webinars: Oct 6 (Start building with PayPal), Oct 7 (APIMatic), Oct 12 (payments dashboard), Oct 13 (Start building with PayPal)

## The brief
"Build What's Next with PayPal and AI." No prescribed problem statements, no tracks. Build an agent, app, automation, payment experience, business tool, social product — anything. The single hard requirement: **the project must meaningfully use BOTH PayPal and AI.**

## Judging criteria
1. **Technological Implementation** — how thoroughly and skillfully the project uses the PayPal Developer Platform and AI tool(s); genuine effort, working non-trivial implementation
2. **Design** — a complete, coherent product experience, not just a technical proof of concept
3. **Potential Impact** — credible, specific case for solving a real problem for a real audience; the demo must show the solution actually addressing it
4. **Innovation/Idea** — creativity and novelty of the concept; differentiation from existing concepts
5. **Presentation** — video clearly demonstrates the project working end-to-end; pitch communicates the problem, the audience, and why it matters

(Criterion weights were not published on the Devpost page as of Oct 4, 2026.)

## Submission requirements
- Working project meeting the build requirements above
- Text description of features and functionality
- **Functional demo** — judges must run or interact with a working build: either complete setup/run instructions in the repo, or a hosted demo URL. Mockups and static prototypes do not qualify
- Tool list — which tools were used and how
- **Public GitHub repo** — all source, assets, run instructions; must be public and open source with a license file visible
- **Demo video** — under 3 minutes (judges aren't required to watch past that); must show the project functioning on the device it was built for; public on YouTube with the link on the submission form; no third-party trademarks or copyrighted music/material without permission

## Entry rules
- Individual or team entries allowed
- New or existing projects allowed, as long as meaningful progress happens during the hackathon
- Must use the free PayPal sandbox environment
- Sponsor AI tools (AG Grid, APIMatic, Elastic, Postman, Render, Zapier, etc.) are optional — any AI tool works as long as PayPal integration is central
- Eligibility excludes: Brazil, Crimea, Cuba, Iran, North Korea, Quebec, Russia
